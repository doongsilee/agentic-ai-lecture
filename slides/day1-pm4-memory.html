reducer 가 지우기도 한다

type Update = Msg[] | { keepLast: number };

messages: Annotation<Msg[], Update>({
  reducer: (prev, next) => {
    if (Array.isArray(next)) return [...prev, ...next]; // 붙이기
    // { keepLast: n } 이면 최근 n 개만 남긴다
  },
}),

// summarize 노드
return { summary, messages: { keepLast: 2 } };
  • 노드는 State 를 직접 고치지 못한다 (오후 ②). 그래서 "지워라" 라는 지시를 돌려주고, reducer 가 처리한다
  • 칸의 값 모양(Msg[])과 노드가 돌려주는 모양(Update)이 달라도 된다
  • Academy 영상은 LangChain 메시지의 RemoveMessage(id) 로 지운다. 우리는 id 없는 OpenAI 메시지라 지시 객체로 같은 일을 한다

  • 같은 thread_id 로 invoke 하면 같은 대화다. 앞 대화는 checkpointer 에 남아 있다가 이어 붙는다
