타입이 틀리면 어떻게 되나?

실행 중에도 막으려면 — zod

노드가 돌려준 값은 어떻게 합쳐지나 — reducer

reducer 는 노드가 돌려준 값을 State 에 합치는 규칙이다. 필드마다 따로 정한다

이론 · L2 Reducers

reducer 는 schema 에 적는다

앞의 값과 새 값을 받아, 합친 값을 돌려주는 함수 하나다

규칙이어 붙이기 [...prev, ...next] · 더하기 prev + next · 덮어쓰기는 안 적으면 된다

defaultreducer 가 있는 필드는 처음 값도 같이 적는다. 이어 붙이려면 빈 배열이 있어야 한다

이론 · L2 Reducers

그래프는 단계로 돈다 — super-step

한 단계에서 실행할 노드들을 함께 돌리고, 단계가 끝나면 돌려받은 값을 한꺼번에 합친다

같은 단계START 에서 선이 둘 나가면 두 노드는 같은 단계에 들어간다. 오래 걸리는 쪽이 있어도 합치는 건 단계 끝에 한 번

다른 단계선을 이어 순서대로 돌리면 단계가 나뉜다. 뒤의 노드가 앞의 값을 덮어쓴다

이론 · L2 Reducers

같은 단계에서 두 노드가 같은 필드에 쓰면?

문법 분석과 어휘 분석을 같은 단계에서 돌린다. 둘 다 notes 필드에 쓴다

reducer 가 없으면한 단계에 값이 둘 온다. 어느 쪽을 남길지 정할 수 없어서 LangGraph 가 에러로 막는다

reducer 가 있으면규칙대로 합친다. 여러 일을 동시에 돌리려면 그 필드에 reducer 가 있어야 한다

이론 · L2 Reducers
