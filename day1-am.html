Agent 는 무엇인가?

flowchart LR
  G["목표: 29일에 교육 2시간 잡아 줘"] --> B
  subgraph AG["Agent"]
    B["두뇌: LLM / 판단 · 계획"] <--> H["몸: Harness / 도구 · 기억 · 상한"]
  end
  H -- "행동: 도구 실행" --> E[("환경: 일정 DB · 점검 기록 · 사람")]
  E -- "관찰: 실행 결과" --> H
  • Agent = 목표를 받아서, 환경을 보고, 행동을 고르고, 결과를 보고 다시 고르는 시스템
  • 고전 AI 의 정의도 같다: 센서로 환경을 인식하고, 행동으로 환경에 작용하는 것
  • 달라진 건 "고르는" 자리에 규칙 대신 LLM 이 들어갔다는 것
  • 한 번 답하고 끝나지 않는다. 결과를 보고 다음을 정한다. 이게 핵심이다

정의는 Russell & Norvig 「Artificial Intelligence: A Modern Approach」 와 HF Agents Course Unit 1 을 따랐다

두뇌는 LLM, 몸은 Harness

두뇌 · LLM상황 판단, 계획, 다음 행동 고르기, 말하기
다음에 할 일 →← 실행 결과
몸 · Harness
손 · 도구실제로 조회하고, 바꾸고, 보낸다
눈 · 관찰실행 결과를 받아 두뇌에 다시 보여 준다
기억 · State지금까지 한 일, 지난번에 한 일
안전장치끝없이 돌거나 위험할 때 멈춘다 · 횟수 상한 · 사람 승인
Harness 란?원래 뜻은 말(馬)에 채우는 마구. 고삐 · 굴레처럼 힘센 말을 원하는 방향으로 일하게 만드는 장비다.
AI 에서는 모델을 감싸서 실제로 일하게 만드는 모든 것. 도구를 쥐여 주고, 결과를 보여 주고, 기억을 이어 주고, 멈춰 세운다
  • 두뇌만 있으면 말만 잘한다. 몸이 있어야 일을 한다
  • 몸 = Harness = 두뇌를 뺀 나머지 전부
  • 같은 두뇌라도 몸에 따라 결과가 크게 갈린다

오전 정리

  • Agent = 두뇌인 LLM + 몸인 하네스. "Agent" 는 넓게 쓰이는 말이고, 모델이 무엇을 정하느냐로 단계가 나뉜다

function runTool(name: string, args: any) {
  if (name === "get_maintenance_plan") return plans[args.tail_no] ? { … } : { error: "정비 계획이 없습니다" };
  if (name === "check_stock") return stock[args.part_no] ? { … } : { error: "재고 시스템에 없는 부품번호 (조회 실패)" };

for (let step = 1; ; step++) {

② 실행 전에 터미널에서 묻는다 (node:readline/promises). 거절하면 실행하지 말고 그 사실을 결과로 돌려준다

성공하면
[TOOL] check_stock({"part_no": "PN-4471"}) → {"재고":1, …}
[사람] PN-4471 1개를 청구할까요? (y/n) y
[TOOL] request_part({"part_no":"PN-4471","qty":1}) → {"청구번호":"REQ-0001", …}
[답]   … PN-4471 1개 청구 접수 (REQ-0001)
정답 · lab/am/answers/bonus.ts
async function ask(question: string) {
  const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
  const answer = await rl.question(`[사람] ${question} (y/n) `);
  rl.close();
  return answer.trim().toLowerCase() === "y";
}

for (const call of reply.tool_calls) {
  const args = JSON.parse(call.function.arguments);
  // 되돌리기 어려운 도구는 실행 전에 사람에게 묻는다. 거절하면 실행하지 않는다
  const result =
    call.function.name === "request_part" && !(await ask(`${args.part_no} ${args.qty}개를 청구할까요?`))
      ? { 결과: "담당자가 청구를 승인하지 않았습니다" }
      : runTool(call.function.name, args);
  messages.push({ role: "tool", tool_call_id: call.id, content: JSON.stringify(result) });
}
